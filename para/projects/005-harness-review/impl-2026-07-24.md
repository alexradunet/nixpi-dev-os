## Known Issues / Deferral

The WS4 split requires careful handling of indentation levels within deeply-nested TypeScript callbacks. The git-extraction-based approach cannot reliably preserve the correct tab structure because the original file contains mixed indentation (some declarations at module level within `default export`, others nested deeper). 

A manual, line-by-line reconstruction of spawn.ts and render.ts — starting from the known-good committed code and carefully deleting sections rather than extracting them — would be needed to resolve this. This is recommended for the lead to handle or for a follow-up iteration.
